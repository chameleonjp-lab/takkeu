# takkeu

タッケウ

Three.jsを基盤にした、ラリー継続型の卓球ブラウザゲームです。スワイプでラケットを動かし、すべての球を失うまでのラリー数を記録します。

## 現在の状態

**第1段階（T01〜T03）の実装です。公開ページはまだありません。**

1球で開始し、スワイプ／マウスドラッグで左右・上下にラケットを動かします。自分の返球だけがラリー数に加算され、球を落とすと結果画面になります。一時停止・再開・再挑戦ができます。相手側の台・人物・ラケット・球は隠れていますが、返球と低めの打球音は継続します。自分の打球音は高めの別音です。

多球・加速・虹色・段階解放・スマッシュは第2段階、自己ベストと設定の保存・実機確認・配布設定は第3段階です。実機操作と音の聞き分けは未確認です。

## 開発

Node.js **24.19.0** / npm **11.9.0** を使用します。

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm run dev
```

```sh
npm run typecheck
npm run test:unit
npm run test:browser
npm run build
npm run preview -- --host 0.0.0.0
```

ゲーム計算は `src/game/`、入力は `src/input/`、Three.jsの表示は `src/render/`、Web Audioは `src/audio/`、画面は `src/ui/` に分離し、`src/app/` が接続します。固定計算刻みは1/120秒です。画面更新が0.10秒を超えた場合は追いつき計算をせず停止します。

[実装記録](docs/progress.md)と[検証記録](docs/verification/stage1/README.md)で、対象コミット、正式ログ、画面・動画・音生成の証拠、未確認範囲を追跡します。CIは型・単体・画面・ビルドを検査し、全文ログと対象SHAを成果物に保存します。マージ・公開は行いません。

## 実装順序

1. 基本ラリー・スワイプ操作・自分と相手の返球音を実装する。
2. 多球・加速・全演出・スマッシュを実装する。
3. スマホでの中断復帰、音、保存、性能を確認し、配布と公開の準備をする。

各段階を個別のプルリクエストとして提出します。マージと公開はユーザーの判断で行います。オンラインランキングは初回計画に含めず、まず端末内の自己ベストを保存します。
