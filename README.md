# takkeu

タッケウ

Three.jsを基盤にした、ラリー継続型の卓球ブラウザゲームです。画面へのタップでラケットを置き、ドラッグで動かし、すべての球を失うまでのラリー数を記録します。

## 現在の状態

**第3段階（T07〜T10）を実装しました。[ゲームを開く](https://chameleonjp-lab.github.io/takkeu/)。**

mainへPRをマージすると、型・単体・画面・配布検査に成功したコミットをGitHub Pagesへ自動反映します。SHAを指定する手動公開にも対応します。[公開・確認・復旧手順](docs/release.md)を参照してください。

名前は任意です。開始前に名前を入力すると、開始時にプレイ回数を1回記録し、終了時のラリー数を[カメレオンの実験場](https://chameleonjp-lab.github.io/chameleonjp_lab/ranking.html?game=takkeu)へ自動送信します。名前・記録は公開され、同じ名前の記録は合算されます。名前なしではランキング対象外で遊べます。途中で「最初から」または「ホームへ」を選ぶと、その時点のラリー数を記録します。

結果画面にはスコア直下の再プレイ、Xでの共有、最高ラリー数の上位30名を表示します。再プレイでは前回のゲーム・入力・音・描画キャッシュを初期化し、ランキングは再取得します。自己ベストや設定、名前、通信失敗中の送信待ち記録は保持します。再送は同じ開始ID・結果IDを使い、回数や結果を二重登録しません。共有URLには実際のゲーム画面を基にしたSNS用画像を設定しています。

このブランチでは初速・毎ラリーの全球加速を速め、返球先を左右へ散らします。450から全スマッシュ、460の足の発光、470以後2ごとの増球、480の全球発光、490の相手側の連続した虹色、500/510のランダムな光、520/530の花火、540の増速、555の曲がるバウンドまで全32行に対応します。無落球なら555で91球です。今回の変更が公開済みかは `release.json` のSHAで確認してください。

追加調整では現在の球速を維持し、バウンド後の見える返球経路まで左右へ分けています。部位別発光の直前・到達時も再検査し、[結果・境界画像・未再現の症状](docs/verification/return-spread-glow/README.md)を記録しています。

このブランチではプレイ画面をブラウザのviewport全体へ広げ、ラケットを指・マウス・ペンの位置へ直接合わせます。離した後も位置と接触を保持します。二本指タップまたはEscapeで停止し、停止メニューから明示的に再開・最初から・ホームへ戻れます。音量・消音・音声再試行は設定または停止メニューにあります。[今回の仕様・証拠・未確認事項](docs/verification/viewport-direct/README.md)を参照してください。Draft PRの段階では公開済みを意味しません。

自己ベスト、効果音音量、ミュート、描画品質を端末に保存します。旧感度の保存データは互換のため保持しますが、直接操作には適用せず、感度設定の表示も撤去しました。回転・アプリ切替・描画や音声の中断時は一時停止し、再開操作を待ちます。保存や音声の失敗時も無音・メモリ内で継続できます。

iPhone 17 Pro Safari実機の操作・60秒性能・VoiceOver、人によるSEの試聴、390の最終的な点滅基準の判定は未確認です。自動ブラウザの成功や公開をこれらの合格として扱いません。[今回の受入対応表](docs/verification/viewport-direct/acceptance.md)に実施範囲と実機確認手順を記録しています。

ラケットの柄と球の貫通表示、虹色球の白い中心の修正、および第1・第2段階と現行仕様の対応は[貫通修正の再照合記録](docs/verification/paddle-stage12/README.md)を参照してください。実装・検証・公開の状態を分けて記録します。

## 開発

Node.js **24.19.0** / npm **11.9.0** を使用します。

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm run dev
```

```sh
npm run typecheck
npm run test:unit
npm run test:browser
npm run verify:release # 型検査・ルート/Pagesのビルドと配布検査を含む
npm run test:performance
npm run preview -- --host 0.0.0.0
```

ゲーム計算は `src/game/`、入力は `src/input/`、Three.jsの表示は `src/render/`、Web Audioは `src/audio/`、画面は `src/ui/` に分離し、`src/app/` が接続します。固定計算刻みは1/120秒です。画面更新が1.50秒を超えた場合は停止します。短い遅延は最大0.10秒だけ計算し、余分な時間を捨てます。

[実装記録](docs/progress.md)と[第3段階の検証記録](docs/verification/stage3/README.md)で、対象コミット、正式ログ、画面・動画・音生成の証拠、未確認範囲を追跡します。CIは型・単体・画面・ビルドを検査し、全文ログと対象SHAを成果物に保存します。

## 実装順序

1. 基本ラリー・スワイプ操作・自分と相手の返球音を実装する。
2. 多球・加速・全演出・スマッシュを実装する。
3. スマホでの中断復帰、音、保存、性能を確認し、配布と公開の準備をする。

各段階を個別のプルリクエストとして提出します。今回の依頼により、初回計画外だったオンラインランキング・SNS共有を追加しました。連携値は[ranking-manifest.json](ranking-manifest.json)、今回の設計は[追加仕様](docs/superpowers/specs/2026-10-23-ranking-share-design.md)を参照してください。
