## 変更と仕様の扱い

- 毎ラリー加速。速度倍率の式を `1 + 1.2 × (1 − exp(−score/200))` とし、従来の5の倍数での倍率・2.2倍上限を保ったまま途中も増加する。新規返球予約から適用し、予約済み時刻・倍率は変更しない。
- 30で2球、40で3球、150で4球、以降10ラリーごとに1球追加。上限なし・落球補充なし。450で無落球なら34球。生存球は発射待ち・相手側の球も含む。
- 相手側の初期表示を取り下げ、発光して解放された部位だけを表示。380は相手床、410は自側床、420は相手壁と相手側の球の再不可視。旧19行から最新21行へ更新した。
- 270は最新の「無地色」を単色として反映し、本体全体の発光を赤へ統一。色の指定はないため赤は初期調整値。任意の確認質問は未回答で、以前の虹色解釈を今回の記載に優先させていない。390からは虹色の強弱へ移る。
- 虹色の頂点色に合う自己発光を適用。未解放の物体を照らして漏らさず、白い球中心・前後の深度関係を維持。形状・基本材質は共有し、可視球へモデルを割り当てて再利用する。落球の計算履歴と球IDの描画割当を増やし続けない。

参考画像の固定画角、ワンバウンド後の画面上の接触、ラケットの扁平な柄、相手の球表面に接する配置は維持する。[preserved-rules.json](preserved-rules.json)はカメラ・接触・軌道・配球間隔・スマッシュ条件・入力・音声・中断復帰・保存の18ファイルが先行修正と同一であることを記録する。加速の設定と増球、表示は今回の明示された改訂である。
