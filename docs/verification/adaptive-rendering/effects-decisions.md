# 追加43条件の対応方針（改訂仕様）

最優先の追加指示により、43条件の全維持は受入条件ではない。分類は**維持8・軽量化2・統合/簡略化13・削除20**。削除20は追加の装飾形状を指し、得点・イベント・既存数字・必要音声を削除する意味ではない。

下表のGPU値はCSS402×874/DPR2/標準、同一の固定状態で4warm+8非同期queryの**scene全体の中央値ms（A→最終F）**。各行を単独演出のGPU負荷/因果的な改善率と解釈したり合計したりしない。早期ラリーの30球配置は診断用で、ゲームの増球仕様を表していない。DOM/CSSと音声の単独費用は未分離。CPUのrallyBuffer.update/送信時間、三角形、draw、転送bytes、実quads、元ファイルのSHA256は正式記録 `manual-effect-decisions.{json,csv}` に保存した。

選択根拠は個別54 ablation、4段階×3組の24比較、床24比較、最終の反復実ゲーム測定を合わせて判断した。単独寄与がばらつきに埋もれた候補は**改善未立証**であり、星空だけをボトルネックと断定していない。装飾を整理した総合効果と、個別の寄与の限界を区別する。[実測による候補選択](revised-effects.md) / [最終結果](final-results.md)。

## データと資源の保持

[開始時の全解放/終了/後継/保持データ表](stage1-investigation.md)は履歴として有効。最終版はgame側の事実をHUD/音声/終了clockに使うため変更しない。新しい追加装飾専用の星配置/流星/輪/電撃を生成するコードを撤去し、時刻やスコアによる一括500ラリー削除は導入しない。共有GPUは2batchをゲーム中ずっと再利用し、retry時clear・view.dispose時一括解放。新hit輪は12分割の不変unit circle、色/位置/ageは事実ごとに独立する。古いboundedな事実の追加pruneは、実ゲーム改善が未立証のため採用しない。元のpause/終了表示clockを守る。

`stage1-investigation.md`中の「実装済み」は開始時6ecの評価である。4batch reuse/3InstancedMesh/既存prune/置換/LOW518400上限を今回新規の最適化として再実装したとは主張しない。外側clip判定のCPU追加、shader統合、indexed geometry再導入は、効果/不具合リスクの実証が足りず不採用。現在描く短いfeedbackには広い常設装飾のculling導入を行わず、動的境界を無視したfrustumCulled=trueも導入しない。

旧装飾形状の検査は新仕様に合わせ置換した。対応元・削除理由・新しい36feedback検査・11予算検査は `revised-test-scope-map.json` と正式JSON/logを参照。ゲーム/入力/音声/ランキング/44コメントの検査は保護し、性能閾値を変更していない。元の全43定義は [6ecのcoverage](https://github.com/chameleonjp-lab/takkeu/blob/6ec38720b4f720c71bf48c5aef3cdc5732fdd578/docs/verification/rally-4000/coverage.md)にハッシュ固定で参照する。
