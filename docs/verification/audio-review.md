# 第3段階の音の検証

対象コミットは[正式マニフェスト](stage3/final-verification.json)を参照。音の実装とブラウザの処理を確認する自動検査、および人による試聴を区別する。

## 実装・自動検査

- 自分：triangle、1150→700Hz、55ms、ピーク0.16。
- 相手：sine、440→220Hz、85ms、ピーク0.16。相手／球の可視状態は参照しない。
- スマッシュ予告：triangle、660→1320Hz、120ms、ピーク0.11。返球音より控えめなピークとし、文字・構えも維持する。
- 3msのアタックと指数減衰。上限8音、終了間近の音から8msでフェード。最大8本のフェード尾も数えた音量余裕を設け、理論最大を0.85以下とする。終了・停止・終了画面・リトライ・破棄でノードを切断する。
- 同じイベント、停止中／ミュート中のイベント、旧runのイベントは再生しない。履歴は時刻順イベントの最新時刻だけを保持する。
- 初回開始・手動再開・音量／音ボタンの操作で再試行する。音声状態が中断するとゲームも停止し、再開操作を待つ。音声再開／ノード作成が失敗しても無音で続行する。

Linux上のPlaywright Chromium／WebKitで、実AudioContextの開始・ノード生成・ミュート・中断・再開拒否・再試行を検査した。OfflineAudioContextで自分／相手／予告／4音／16音（8音とフェード尾を想定）のWAVを合成し、ピーク・RMS・非無音を測る。数値とWAVは[媒体一覧](stage3/README.md)と正式結果に保存する。これは波形の信号検査であり、実際の端末スピーカーの音割れ・快適さ・識別の合格ではない。

## 人による試聴

| 確認 | 結果 | 端末・条件 |
|---|---|---|
| 実プレイ中の自分音／相手音の識別 | 未確認 | 音声を聴く環境・試聴者なし |
| 4球・上限の重なりでの不快な歪み／音量 | 未確認 | WAV合成のみ。実再生していない |
| 予告音と返球音のバランス | 未確認 | 数値の余裕のみ。聴覚上のバランスは未確認 |
| iPhone Safariの開始・アプリ切替・画面ロック・復帰 | 未確認 | iPhone実機なし |
| iPhoneの本体スピーカー／イヤホン | 未確認 | 出力端末・OS／Safari版を記録して要試聴 |

公開前に対象SHA、iPhone機種、OS／Safari版、出力先、音量・ミュート設定、再開前後の状況、識別可否と快適さを追記する。修正したら該当する波形・ブラウザ検査と試聴を更新する。未確認のまま公開可能と扱わない。
