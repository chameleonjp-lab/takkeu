# 第3段階・全要件の受入結果

この表は第3段階の対象コミット時点の記録。公開後にユーザーから見える接触と3D平面判定の不一致が報告され、再現した。R01/R04/Q01/Q05/Q08/Q09と台・ラケットの初期表示の改訂および再検証は [接触修正の受入記録](contact-fix/README.md) を参照する。この履歴の自動検査成功を、人が操作した際の遊びやすさの確認と同一視しない。

対象仕様：[正式要件・設計書](../superpowers/specs/2026-10-22-takkeu-design.md)。対象範囲：T07〜T10と既存T01〜T06の回帰検査。
正式な対象SHA、各コマンドの終了コード、実行時刻、ソース・配布物のハッシュは[最終検証マニフェスト](stage3/final-verification.json)を正とする。[全文ログと媒体一覧](stage3/README.md)、[試聴記録](audio-review.md)、[公開手順](../release.md)も参照。

「成功」は記載した方法と条件での成功。「未確認」は未実施／証拠不足で、合格に数えない。失敗した途中の検査は[作業台帳](stage3/work-log.md)と各初回全文ログへ残し、修正後の正式結果と区別する。最終的な未解決の実装不具合が判明した場合は「失敗」とする。

実機・試聴・390の最終点滅判定には未確認がある。**公開準備までで、公開可能・公開済みとは判定しない。**

| 対象 | 結果 | 条件 |

機能要件の変更はない。公開用の得点変更、自動操作、開発用画面は配布物へ含めない。試験専用の得点・自動操作はtests/の独立入口だけにあり、保存先もメモリ内へ差し替えるため端末記録を汚さない。`build:pages`の明示コマンドは計画書4節の許容方式に従う。


補助測定では、描画準備後のChromiumは60.017秒・4球・実スマッシュ10回の連続負荷が成立したが、p95 33.3msで参考25ms条件は未達。WebKitは0.767秒で再停止した。元の冷状態計測の失敗と分けて[記録](stage3/README.md#初回描画後の補助切分け)した。iPhone目標は未確認のまま。

GitHub CIは証拠追加head b06b646のPR／push実行とも全工程成功を確認した。公式GitHub StatusのActions Results障害により、初回は結果報告が遅れていた。未確認時と成功確認後を[実行記録](stage3/README.md#draft-prgithub-ciの外部制約)で分ける。最新の文書追加headはPR本文・Checksで追跡する。
