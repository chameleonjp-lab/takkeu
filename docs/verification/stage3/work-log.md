## 調査と修正

- 設定画面の不在、保存読戻し・品質上限の未実装をREDで確認した。保存拒否・破損・不正値は既定値／メモリ内へ戻す。
- WebGL喪失中も再開ボタンを押せた旧動作をREDで確認。復旧中の再開を無効にし、復旧後は描画のみ再作成する。
- 旧resumeの遅延失敗が新しい成功を取り消す不具合、音声出力の初期化失敗後に無音のままになる不具合をREDから修正した。
- 音声の重複履歴は時刻順イベントの最新時刻だけを保持する。8音＋最大8本の8msフェード尾を想定した音量余裕を確保し、終了・停止・リトライで全ノードを切断する。
- 設定検査の非表示要素の重複選択、固定刻みと一致しない再開後時刻の断定、音量フェード検査で新しい音のアタックを読んでいた箇所を修正した。各初回ログを保持した。
- Linuxの不足ライブラリを公式Debianパッケージから/tmpへ展開し、WebKitのローカル探索先へ配置した。実ブラウザは起動・検査成功。CIにはこの回避を入れない。
- ローカルのNode孫プロセスによるgit実行は既定sandboxでEPERMになった。ネットワーク許可付き実行で同じ検査を成功させた。公開照合コードを緩めていない。
- 配布検査の初回は実時計の描画遅延停止で操作できず失敗した。配布機能の確認は制御した時計、実時間の性能計測は専用検査へ分けた。並行Playwrightの出力先の衝突も解消し、正式検証は順次実行する。
- 公開main照合を外すと負例検査が失敗することを確認し、照合を戻して成功した。

ゲームのルール・球速・接触・加速・解放条件の変更はない。build:pagesは計画書が認める明示的コマンドを採用する。実機・試聴・点滅基準の未確認は公開前の残件として扱う。
