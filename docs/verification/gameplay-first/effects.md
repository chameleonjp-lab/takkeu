# 旧43条件と今回の方針

現行mainには既に削除/統合された形状がある。今回新たに削除した演出はなく、虹の細かい帯だけを簡略化した。旧一覧の「4000後も続行」は現在の3500終了仕様には適用しない。

実測負荷欄の「なし」は旧形状が現行コードに存在しないことを示し、共有フレームのCPUが0msという意味ではない。短い弧、HUD、音の単独負荷は今回未分離。旧表の全scene時間を単独費用へ転記しない。今回の新しい共通最適化の比較は[README](README.md)とPRのRendering comparison artifactを参照。全43条件を今回独立計測済みとは主張しない。
