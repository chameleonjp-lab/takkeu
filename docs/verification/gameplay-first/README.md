## 仕様と採用内容

43条件の全維持、削除禁止、画素一致、密度固定は要求しない。得点、最大30球、球速、難易度、入力、衝突、終了、ランキング、PR26の結果、音声は保護する。現行PR27は3500終了なので、4000は描画専用診断として扱う。

現行mainでは星空・流星群・多重光輪の常設形状は既に削除されている。再度削除したとは数えない。旧43条件の記録は [既存の対応表](../adaptive-rendering/effects-decisions.md) と [旧最終結果](../adaptive-rendering/final-results.md)。これらは当時の履歴であり、後の3500仕様や今回の結果で上書きしない。[今回の43行確認](effects.md)。

新しい変更は描画2ファイルのみ。
- 平面コートを425頂点/768三角形から4頂点/2三角形へ。
- 白線を153頂点/256三角形から4頂点/2三角形へ。
- 直線ネットの16分割を端点だけへ。主ネット1792→112頂点。
- 空間虹色の細かい色帯を単純な補間色へ簡略化。形、寸法、UV端点、材質、透過率、球とラケットの位置を維持する。
- 短い到達電撃、落球表示、通知、スマッシュ警告、白い球の中心、音声を維持。今回はこれらを削除しない。

## 正式な再実行

専用 `Rendering comparison` PR workflowはChromium/WebKit×標準/低負荷で、PRのbase/headを同一runnerで比較する。390×844/DPR2、4段階×各60実秒、各1対。順序を段階ごとに入れ替える。全source hash・全RAF・simTime・物理score・30球・資源・heap・画像・失敗を90日artifactへ保存する。実行成功と性能達成を分け、p95≤25ms/25ms以内≥95%/sim≥59秒/全30球を変更しない。停止した場面の低p95を合格にしない。単回比較から統計的優越や全端末の快適性を主張しない。

既存CIの型検査、全単体、Chromium/WebKit操作/負荷、root/Pages配布を保護。製品sourceのdiffは2ファイルだけで、game/input/app/audio/ranking/ui/DB/releaseフローを変更しない。PR CIから公開しない。

自動画質の採否は今回の高DPR比較が揃うまで未判定。旧候補は[切替時80–423.1msの待ちを理由に撤回](../adaptive-rendering/stage2-rejection.md)されているが、その旧測定を今回の実測に流用しない。解像度切替、カメラ、touch mapping、保存値の変更は含めない。
