# 独立レビューと修正

対象：main `8af2b6e` からの匿名開始・保存・API・マイグレーション・集計・検査の全差分。読み取り専用の別レビュアーが実コードで再現検証した。

- Criticalなし。SQLの任意権限露出なし。専用表だけへの記録、要求ペイロードに名前/スコアがないこと、既存の名前あり集計維持を確認。
- Important：同じlocalStorageへ各タブが古いキュー全体を書き戻し、別タブの未送信開始が消える。オフライン2タブと、ACKによる上書きの2件を失敗するunitで再現。通常のWeb Storageは開始IDごとの独立キーに変更し、他の開始記録を上書き/削除しないよう修正した。
- 再送契機の喪失：古い送信の失敗中に始めた次のプレイが再送されない。ユーザーの回数を記録する目的から実装者はImportantとして扱った。失敗するunitを追加し、新規開始が重なると1回の追加ドレインを予約する修正を行った。継続的な無制限再送ではない。
- 上記3件はREDを確認し、修正後23件のランキングunitが成功。全unit366件・型・関連browser14件も成功。
- 実装者の追加検査でonline通知と古い通信の失敗順の競合もREDで再現し、完了後の再送で修正。スコア送信・名前あり処理は従来のまま。

見送り事項なし。レビュアー自身は本番DB試験・全テスト・配備SHAを独立に確認していないため、DB rollback検査・CI・公開確認を実装者が担当する。
