低p95の観測範囲はB183.4–200.0ms、候補133.4–149.9ms。事前の3組の改善率33.2666% / 27.2628% / 25.0500%、sim増加4.8009 / 5.3365 / 4.8914秒/60秒。最良の回だけを使っていない。n=3の反復範囲であり、母集団の信頼区間や他端末の保証ではない。初回の部分frameを除く感度分析でも結論は同じ。全18回で25ms/95%/59秒の絶対基準は失敗。

GPUは別の12秒診断で低p50（nearest-rank）86.52→61.88ms（非disjoint query）。偶数個の場合の算術中央値は変更前86.636372msであり、p50と区別する。これは描画命令をCPUで送る時間やRAF間隔と別の値であり、SwiftShader上のGPU相当区間。長時間試験では追加queryによる観測負荷を避けて取得していない。GPU欠測はnull。音声・描画資源は同じfull collectorで採取した。RAFで採った音声同時数の最大値と、native生成時に記録したpeak（warmupを含む）を分けて保存する。
