# iPhone17Pro Safari実機確認（未実施）

本セッションに物理端末はない。Chromium/WebKitの端末presetは実機結果ではない。次の手順はiPhoneの画面操作だけで測定・JSON保存できるテスト専用ページを使用する。配布用ビルドには含まれない。

## 準備

管理者がこのコミットをローカルに取得し `npm ci`、`npm run dev -- --host 0.0.0.0 --port 4173` を実行する。同じ信頼済みLANからSafariで `http://<開発PCのLANアドレス>:4173/tests/fixtures/performance-iphone.html` を開く。これは開発用URLであり本番公開しない。LAN接続不可なら既存承認方針に従った一時的な私有テスト環境を別途用意する。本依頼では公開・デプロイしていない。

このページはランキングの模擬応答を使い、さらに同一origin以外のfetchを拒否する。本番Supabaseへスコアを送らない。Web Inspectorは不要。ページ・起動中のViteは試験終了後に閉じる。

## 計測

1. iPhoneモデル、iOS/Safari版、対象commit、画面方向、電源/低電力状態、充電有無、室温、開始時の熱さ、画質を記録する。画面収録の有無も記録し、比較間で揃える。
2. 「パネルを閉じる」から設定で画質/音量を選び、「はじめる」でGPU/音声の準備完了を待つ。
3. 「診断」を開き1500/2600/3000/4000を選ぶ。30球自動返球を有効にして「60秒計測」。パネルは計測中に消える。停止が発生しても自動再開しない。
4. 終了後「測定JSONを保存」からファイルへ保存する。p50/p95/p99、25ms以内割合、simTime進行、全frame30球/phase、停止理由、音源数と実描画サイズを確認する。実行完了を性能合格としない。
5. 各スコア/画質を2回。4000は冷えた開始時と、通常プレイを続けて5分/10分後でも同じ手順を行う。ブラウザ再読み込みと起動準備の有無を記録する。発熱時の劣化やSafariの中断を省略しない。
6. 別試験で自動返球を外し、指追従・反応の遅れ、左右端での位置一致、小さい球の白い中心、スマッシュ警告、電撃と球の識別、音量/ミュート/一時停止/再開を人間が確認する。人の反応をRAF値から推定しない。入力遅延のms定量化には外部高速度撮影等が別途必要で、未実施なら未確認とする。
7. 「動きを減らす」、文字拡大、VoiceOver、縦横切替を別試験で確認する。HDR/正式WCAG判定はこのSDR計測から推定しない。

計測ページは軽量な端末用方式で、Linuxの正式比較とはwarmup/自己ベスト初期化/資源採取頻度が異なる。相互に数値を直接比較しない。人間の試聴・視認・熱さはJSONに自動入力されないため別メモを添える。
