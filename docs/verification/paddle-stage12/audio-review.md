# 音声処理と試聴の区別

最終製品対象：`77f21a5f213d2f3d848a81fc743fcad890c77d6c`。音声のソースは基準mainと同じ。今回の正式画面検査でもLinuxのChromium156／WebKit27.2で実AudioContextとOfflineAudioContextを動かした。iPhone実機ではない。

| 対象 | 自動処理の検査 | 人による試聴 |
|---|---|---|
| 自分の返球 | triangle、1150→700Hz、55ms | 未確認 |
| 相手の返球 | sine、440→220Hz、85ms、不可視でも実打球で発音 | 未確認 |

| 中断・再開・リトライ | 停止・旧runの音を破棄、拒否時の無音続行と再試行、実ノードの切断 | 実iPhoneの切替・ロック・復帰とスピーカー出力は未確認 |

ブラウザ音声処理の検査は成功。今回合成したWAVは[audio](audio)、実ノード・合成波形の記録は[data](data)と[正式画面ログ](final-browser.log)へ保存した。波形やピークの違いだけで「実際に聞き分けられる」「バランスが良い」とは判定しない。

音声出力を聴ける端末で試聴していないため、端末名・OS／Safari版・スピーカー／イヤホン・端末音量・ゲーム音量を指定した試聴結果は未確認。自他の識別、4球、予告と返球のバランス、復帰直後と終了後を確認対象に残す。
