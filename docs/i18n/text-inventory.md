# 表示文言インベントリ

対象はタッケウのアプリ内表示、読み上げ、入力placeholder、進捗、通知、エラー、賞状PNG・alt・共有タイトル、X共有文。比較元は `origin/main` の `84b9122713b280255d762978c4bf9906f8b1987b`。全ソースキーは [source-messages.json](source-messages.json)、実装の日本語基準は [ja.ts](../../src/i18n/locales/ja.ts)。

248個のユニークキーを収録する。各言語は同じ248キーを持ち、空訳・プレースホルダー不一致はないことを辞書データで照合した。表の「全15」は `ja, en, es, pt-BR, zh-Hans, fr, de, ko, ru, it, zh-Hant, id, tr, vi, th`。画面表示・各ブラウザでの検証実績は [release-readiness.md](release-readiness.md) に分けて記録する。この文書の辞書照合を実機検証の完了とは扱わない。

## 監査範囲と再現方法

`src` 配下81ファイルを列挙し、辞書15ファイルを除く61個のTypeScriptファイルについて、日本語・英語の表示文字列とDOMへの書き込みを調べた。`git show origin/main:<path>` の変更前ソースと現在の表示側を比較し、HTMLのテキストノード、`aria-label`・`aria-valuetext`・`placeholder`・画像`alt`・`document.title`、Canvasの`fillText`、例外生成とその表示経路、共有本文も確認した。ソースに残る日本語だけを検索して完了とはしていない。

再現する検索の例：

```sh
rg --files src
rg -n '[ぁ-んァ-ヶ一-龯]' src --glob '*.ts' --glob '!src/i18n/locales/*'
rg -n 'textContent|innerHTML|innerText|setAttribute|placeholder|aria-label|aria-valuetext|fillText|throw|\.title|\.alt' src --glob '*.ts' --glob '!src/i18n/locales/*'
git show origin/main:src/ui/screens.ts
git show origin/main:src/ui/certificate.ts
git show origin/main:src/ui/rallyNotice.ts
```

抽出元は screens 128項目、loading関連45項目、certificate 30項目、result comments 44項目、共有文・タグ5項目。共有キーを重複排除すると248件になる。抽出後に全ソースを見直し、元の英語キャプション、文書タイトル、最大30球の補足、3種類の終了読み上げと6種類の停止理由まで照合した。新規言語ラベル・公開ルールの開閉ラベル・最大30球の補足は表で「今回追加」と記す。

## エラーの表示境界

`Q/K/V/W/P/A` には原文の日本語エラーが残る。これは例外・状態の原文を保持し、`screens.setError` または `loading.show` の `translateError` で選択中の言語に変換する設計である。ソースの日本語残存をそのまま表示漏れと判定しない。
