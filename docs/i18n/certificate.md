# 多言語のクリア賞状

`src/ui/certificate.ts` は共通の `t` と15言語の辞書を使用する。名前、正式な殿堂番号、達成条件、PNGの寸法は翻訳によって変更しない。

## 日付・名前・正式番号

- `certificateDate(timestamp, language?)` は選択言語の `Intl.DateTimeFormat` を使用し、タイムゾーンを常にUTCに固定する。たとえば `2026-10-27T23:15:00-05:00` は英語で `October 28, 2026`、日本語で `2026年10月28日` になる。タイ語はロケールの暦に従い `28 ตุลาคม 2569` になるが、同じUTCの日を表す。
- 名前は辞書キーにせず、名前付きプレースホルダーへそのまま渡す。DOMには `textContent` または `alt` 属性として設定し、HTMLとして解釈しない。画像では折り返しても名前を省略しない。
- `CertificateData.hall` がある場合だけ、受領済みの正式番号・登録名・登録日を使う。番号が未受領・対象外・名前なしの場合は達成日時を使い、「殿堂番号なし」を示す。番号を推測・採番しない。
- 表示する番号と落球数には共通の数値書式を使う。保存名は従来どおり `takkeu-3500-clear.png` または `takkeu-3500-hall-1234.png` のような未整形の番号を使う。

## 画像とフォント

出力は従来どおり900×1200のPNG。生成前に `document.fonts.ready` を待ち、生成後は作業用canvasの寸法を0に戻す。画像生成は保存ボタンの操作時に実行し、ゲームの描画ループには入れない。

端末にインストールされたフォントをOSのライセンスの範囲で使用する。日本語の明朝体を優先しつつ、言語に応じてNoto Sans Thai、Thonburi、Leelawadee UI、Noto Sans CJKの各地域版、Apple SD Gothic Neo、Malgun Gothic、PingFang、Microsoft YaHei/JhengHeiを選ぶ。Noto SansやArialはラテン文字・キリル文字を、絵文字用フォントは絵文字を補う。フォントファイルの再配布や、生成時の外部フォント取得は行わない。

本文は730px幅の領域内で単語単位に折り返す。長い単語や名前は書記素単位で折り返し、結合文字や絵文字の途中で切らない。`Intl.Segmenter` がない環境では結合文字・ZWJ・肌色・国旗をまとめる代替処理を使う。行の実測幅と上下の実測境界を使い、各領域の高さに収まるまで文字サイズを調整する。最小14pxでも収まらない入力では、はみ出す画像を保存せず生成エラーを表示する。

## 言語切替と非同期処理

`createCertificateImage(data, document?, language?)` の第3引数は省略でき、従来の呼び出しを維持する。省略時も関数呼び出し直後に言語を確定し、フォントやPNGの完了を待つ間に言語が変わっても画像内の文言を混在させない。

コントロールの世代キーには言語を含める。言語変更・再挑戦・画面離脱・破棄で世代を進め、表示中のBlob URLを解放する。古いPNGの成功・失敗と画像共有の失敗は新しい結果に反映しない。言語変更後はボタンで新しい言語の画像を作成できる。

見出し・説明・ボタン・保存案内・画像の代替テキスト・カードのアクセシブル名は既存DOMへ再適用する。言語の変更でボタンを作り直さず、フォーカスを維持する。`dispose` はイベントと共通言語の購読を解除する。

## 検証

`npm run test:unit -- tests/unit/i18n-certificate.test.ts` の29件で、UTCの日付、言語の確定、15言語の画像領域、混在文字の名前、正式番号の有無、HTMLとして解釈されない名前、非同期結果の世代、URL解放、DOMの同一性と購読解除を検査する。言語切替のテストは英語の一部文言だけを固定した辞書データで境界を検査し、翻訳全文の網羅性は共通の辞書テストが担当する。canvasの単体テストには測定用の代替実装を使うため、実際のフォントの字形はブラウザ検証が必要。

2026-10-30の担当範囲の検証では、賞状・クリア結果・正式番号の単体テスト3ファイル34件が成功。新しい言語・画像世代のテストは変更前の失敗も確認した。全体の `npm test` は翻訳辞書と既存テストを他の作業と並行して変更中の段階で1035件成功・34件失敗だった。失敗は `i18n-catalogs`、`i18n-sharing`、`i18n-screens`、`startup-app`、`release-revision` にあり、賞状の単体テストには失敗がなかった。全体の型検査は一度成功した後、辞書の型変更による共通翻訳処理と辞書テストの文字列索引エラーを検出した。最終統合時に全体を再検査する。

既存の `goal-clear.spec.ts` と `certificate-ownership.spec.ts` をChromium/WebKitで実行しようとした時点では、既定の保存場所にブラウザ実行ファイルがなく、18件とも起動できなかった。別途準備されたブラウザを使ったPNGの字形・保存・共有・画面離脱の検証は統合側が担当する。この結果をブラウザでの成功として扱わない。

端末にフォントが存在するかはOSに依存する。LinuxのNoto環境とブラウザの実行結果は、iPhone実機での字形・保存・共有操作の確認とは区別する。
