# 言語の自動選択と手動変更

実装は [languages.ts](../../src/i18n/languages.ts) と [i18n.ts](../../src/i18n/i18n.ts)。専用保存キーは `takkeu.language.v1`。既存の名前・設定・自己ベスト・送信待ち記録のキーを再利用しない。

## 初回表示の優先順位

1. 保存キーの値が15個の有効な言語IDなら、その手動選択を使う。
2. 保存値がない・無効・読み出し失敗なら、`navigator.languages` の配列順に対応言語を探す。
3. 配列から対応言語が見つからなければ、`navigator.language` を調べる。
4. 有効な言語情報があるが、すべて非対応なら `en`。
5. 言語情報を取得できない、配列が空で `language` も空、空白のみなどの場合は `ja`。

ブラウザ言語は初期候補を選ぶための値で、自動判定しただけでは保存しない。有効な保存済み手動選択がブラウザの設定より優先する。生のlocale（`en-GB` 等）を保存値としては受け付けず、登録したIDを保存する。

| 取得・保存例 | 選択結果 |
| --- | --- |
| 保存 `th`、ブラウザ `ja-JP` | `th` |
| 保存値なし、`languages=['es-MX','ja-JP']`、`language='en-US'` | `es` |
| `languages=['xx','de-DE']`、`language='fr-FR'` | `de` |
| `languages=['xx']`、`language='fr-FR'` | `fr` |
| `languages=['xx']`、`language='xx'` | `en` |
| `languages=[]`、`language` なし | `ja` |
| navigatorを取得できない | `ja` |
| 保存値が `invalid`、ブラウザ `es-ES` | `es` |

## 地域タグの正規化

前後の空白を除き、小文字化し、`_` を `-` に置き換える。`ja-JP`→`ja`、`en-GB`→`en`、`es-MX`→`es` のように、基本言語が対応していればその辞書へ割り当てる。

| ブラウザタグ | 辞書ID |
| --- | --- |
| `pt-BR`、`pt-PT`、`pt` | `pt-BR` |
| `zh-Hant`、`zh-Hant-CN` | `zh-Hant` |
| `zh-Hans`、`zh-Hans-TW` | `zh-Hans` |
| `zh-TW`、`zh-HK`、`zh-MO` | `zh-Hant` |
| `zh-CN`、`zh-SG`、`zh` | `zh-Hans` |
| `zh_HK`（アンダースコア） | `zh-Hant` |
| `xx`、`ar` 等の非対応基本言語 | 対応なし。次の候補へ |

中国語は明示的なスクリプトを地域より優先する。`hant` があれば繁体、次に `hans` があれば簡体、それ以外は `tw/hk/mo` の地域を繁体にする。ポルトガル語はブラジル版の辞書1種類に統一する。対応localeの全一覧は [languages.md](languages.md)。

## 手動変更とストレージ失敗

ホーム・設定・一時停止メニューに同じ15項目の言語selectを置く。プレイ中は一時停止して変更でき、再開・リトライを自動実行しない。ラベル・`aria-label` は現在の言語で、optionは常に各言語の自称、optionの `lang` はそのID。変更するとすべてのselectの選択を同期し、`html.lang`・タブタイトルと既存DOMの文言・属性を更新する。

有効なIDを指定すると保存を試みる。保存APIの取得・`getItem`・`setItem` が例外を投げても、現在のページではメモリ上の言語を切り替え、通常どおり画面を更新する。保存できなければ再読み込み後の維持は保証せず、次の起動で同じ優先順位を適用する。言語処理の失敗でゲーム開始を止めない。無効なIDは状態変更・保存・イベント発火を行わない。

同一IDの再指定は保存を試みても変更イベントを増やさない。購読は表示コンポーネントの破棄時に解除する。言語変更だけを理由にゲーム状態、canvas、WebGL、音声、スコア保存、ランキング通信、プレイ回数を作り直さない。

## 画面状態と非同期処理

静的文言だけでなく、現在の順位・登録状態・エラー・停止理由・読み上げ用文・Xリンクも選択言語で再表示する。登録名、スコア、正式番号、時刻の元データは保持する。準備中の段階とエラーは原文のまま保持し、表示時に翻訳するので、通信完了後も現在の言語を使える。

賞状PNGは結果と選択言語に属する。言語変更時に古いプレビュー・共有ファイルとobject URLを破棄し、処理中の旧言語画像が戻っても現在の画面へ反映しない。新言語の賞状は作成ボタンから生成する。詳細は [certificate.md](certificate.md)。

`initializeLanguage` はアプリの生成時に保存・navigatorを受け取る。単体モジュールとして文脈なしに使う場合の既定は日本語。初期HTMLは `lang=ja` のまま配布し、アプリ起動時に決定したIDへ切り替える。OGPは変更しない。
