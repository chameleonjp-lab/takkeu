## 実際に検出して修正した問題

- 英語の匿名賞状に「プレイヤー」が残る問題を修正。匿名の既定名だけを翻訳し、実際の同じ文字の名前は保持。
- 既知のエラーは詳細を維持して翻訳し、未知の例外は日本語を含めて選択言語の汎用エラーへ。英語のテスト内部識別子も表示しない。既存のエラー/手動再試行テストは失敗状態・不正HTML要素不在を保ち、文言の期待値を翻訳仕様へ厳密に更新。
- WebKit配布物テストにも明示的な日本語ロケールを指定。従来の日本語操作条件を維持。
- Ubuntuの代替フォントで開始ボタンが700px外へ出ることをCIが検出。本文を削らず、余白と導入見出しをコンパクトにし、名前の公開説明は全文を開閉できる形へ。言語欄は自然なヘッダーの高さに含める。元の700px/44px条件は変更しない。
- NodeとWebKitのCLDR差でイタリア語の4桁区切りが異なる問題はテストの期待値計算をブラウザへ移動。数値の内容、正確な翻訳文、UTC日付の照合は維持。
- ローカライズ前にも失敗する古いGL診断fixtureを修正。描画コードは変更せず、元の4回上限に加えて、有効な30球/実落球/両batchが厳密に2回で描かれることを要求。

## 連続切替・画像とメモリ

30回の同期切替で、イベント登録/解除数、canvas/input surfaceの同一性、スナップショット、view作成/破棄回数、GPU資源が変化しない。実際の一時停止メニュー選択でも停止状態と資源を維持してから再開できる。

Chromiumでは強制GC後のヒープを測定した。45回の事前切替後は2,878,056byte、150回後は2,891,076byte、さらに150回後は2,905,804byte。DOM node1375・JS event listener18・document1はすべて一致し、全可視要素も286で一定。計測用コード/エンジン管理領域も含む微増で、長時間の完全な無漏れを証明するものではない。WebKitには同じヒープAPIがないため、DOM・状態・リソースと画像所有権を検査し、ヒープを測ったとは扱わない。

PNGは言語変更時に古い処理を棄却し、3回の実生成で古いBlob URLがfetchできなくなることまで確認。離脱後もURLを解放する。同一スナップショットの20描画では翻訳関数を呼ばない単体検査もある。

## 描画負荷と制約

8通りの実フレーム60秒（2ブラウザ×標準/低負荷×450/555開始）はエラーなく完走。61ファイルの保護対象に描画・物理・音声を含め、確保済みgeometry55/texture4/program17、particle容量8408、rally容量6872を維持した。旧GL fixtureのmain再現、修正後2/2と比較数値は [performance-fixture.md](performance-fixture.md)、生の数値要約は [performance-results.json](performance-results.json)。

Linux参考目標「95%以上が25ms以内」は、変更前mainと現在の両方で未達。比較4条件のp95は166.7→166.6、100.0→100.1、56→56、45→48ms。基準を緩和して成功と見なさない。単発の別時刻の比較からタイミングの同等性や小差の原因を断定せず、iPhone実機の性能合格とは扱わない。歴史的4000フレームの全診断/全反復を実行したとも扱わない。

## 環境・画像・公開前確認

Node24.19.0 / npm11.9.0 / Playwright1.64.1、Linux Chromium156.0.8078.4 / WebKit27.2。Linux上のNotoフォントとOS代替フォントを使用。有料フォントを同梱せず、実行時の翻訳/フォントAPI通信を追加しない。

実行環境はDebian13で、追加共有ライブラリは`/tmp`へ展開した。WebKit wrapperが環境のライブラリ検索パスを置き換えるため、展開ライブラリをその検索先へリンクした。ldconfigに未登録のためホスト事前検査だけを無効化したが、実際のブラウザ起動/全テストとアサーションは実行した。ブラウザやゲームのテスト条件は緩和していない。Nodeの本番GET検証には継承proxyを使う `NODE_USE_ENV_PROXY=1` が必要だった。
