# 累計100落球で終了 Implementation Plan

**Goal:** 1プレイの累計落球数が100に達した瞬間、残球があってもゲームを終了する。
**Architecture:** SimulationStateとGameSnapshotにlostBallCountを追加し、実際のball-lostイベントだけで加算する。100球目で以後の同一刻み内の処理を打ち切る。残球0での終了は維持する。
**Spec:** この会話の「100球落としたらゲームオーバーにしましょう」。

## Constraints

- 99球までは残球があれば継続し、100球目で一度だけ終了する。100より後の落球・返球・加点を処理しない。
- カウントは同じプレイ中に累積し、一時停止・再開で保持、再挑戦・ホームからの新規開始で0へ戻す。
- 落球数と上限をHUDに表示し、100球で終了した理由を結果画面に示す。
- 最大30球、増球間隔、速度、虹色表示、シェア・ランキングを保つ。

- [x] 落球数と終了判定、HUD・終了理由を実装する。
