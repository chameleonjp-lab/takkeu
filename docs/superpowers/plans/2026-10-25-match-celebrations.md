# 落球・ラリー演出 Implementation Plan

**Goal:** 最新依頼の電撃・連続落球・数字・ゾロ目・100単位の音と点滅を漏れなく実装する。
**Architecture:** シミュレーションには演出の発生時刻と値だけを保存し、描画は固定バッファの別レイヤーで行う。描画頻度・一時停止・描画復旧で演出を重複させず、当たり判定や球速へ影響させない。
**Tech Stack:** TypeScript, Three.js, Web Audio, Vitest, Playwright.

## Requirements

| 条件 | 演出・期間 |
| --- | --- |
| 毎回の落球 | ネットから電撃。2秒以内の次の落球で連続数を増やし、電撃の数と大きさを増大 |
| 連続落球4球以上 | 電撃に加え、台・ネット・脚を減衰振動。床・壁・球・入力座標は動かさない |
| 落球10・20…100 | 自側コート面に大きく発光する数字。通常2秒、複数同時到達でも全部を表示 |
| 落球55 | 虹色／黒で3秒間点滅 |
| 落球77 | 虹色／青で3秒間点滅 |
| 落球88 | 虹色／緑で3秒間点滅 |
| 落球99 | 虹色／金で3秒間点滅 |
| ゾロ目ラリー | 11・22…99・111・222…（2桁以上）。台の縁から緑の電撃を5秒間 |
| 100・200…ラリー | ファンファーレを一度鳴らし、床と壁を虹色／金色で5秒間点滅 |

## Constraints and Rulings

- 色の切り替えは0.3秒ごと。77/88/99の期間も55と揃え3秒とする。
- 連続判定は前の落球から2秒以内。次の落球まで2秒を超えたら1に戻す。
- 効果はプレイ中の時間で進め、一時停止中は止める。新規プレイでは全て初期化する。
- 早い連続落球で10と20などを同じ描画刻みに跨いでも、全ての数字を保持して表示する。
- 100球でゲームの計算は直ちに終了。最後の電撃・数字・点滅を最大5秒見せてから結果へ進む。結果が遅れても得点やランキング終了記録は即時に確定する。
- 100単位の音は既存音量・ミュート・停止・再開始を尊重し、密集した打球音で途切れさせない。
- 一時的な床壁の点滅は独立レイヤーとし、終了後は元の段階の表示へ戻す。
