# 加速・配球・後半ラリー実装計画

> **For agentic workers:** Use superpowers:executing-plans. 本担当が既存worktreeで順に実装し、設計と最終差分は別コンテキストでレビューする。

**Goal:** 中央配球と停止の早さを改善し、全球加速と450〜555の新しいルール・演出を実装する。

**Architecture:** 既存の固定計算・透視投影接触を保つ。ゲーム内時刻を使う連続した軌道の再時刻付け、待機球の再予約、独立した発光/粒子モジュールを追加する。

**Tech Stack:** TypeScript / Three.js / Vitest / Playwright Chromium・WebKit。

**Spec:** [今回の設計](../specs/2026-10-23-extended-rally-design.md)。今回の明示指定が旧ルールより優先する。

## Global Constraints

- 初速1.00秒、gain1.6/decay90、全球に毎ラリー適用。飛行位置の連続性、入力・発光・予告の停止中の時計を保つ。
- 停止は1.50秒超。短い遅延の追いつきは最大12刻み・0.10秒で打ち切り、残りを捨てる。
- 450から相手の全打球がスマッシュ、540で係数1.60。予告0.40秒。
- 470以後2ラリーごとに増球。480の全球発光、490の相手側連続模様、500/510のランダム、520/530の粒子、555の曲がるバウンド。
- 新しい得点操作や自動プレイはテストに限定。公開物へ含めず、自動マージしない。

## Review Focus

- 同時接触と加速でも位置が飛ばず、二重加速・加点・発音・粒子を起こさない。
- 予告中の球の再予約が早出しや重複予告にならず、450直後の追加球も通常返球にならない。
- 470を跨ぐ複数加点で旧10ごとの報酬を二重に足さず、待機球だけでも終了しない。
- 555のバウンドで球が瞬間移動・台外着地・描画と判定の不一致を起こさない。
- 低FPS・描画再作成・ホーム・再挑戦で過去の時間や粒子・GPU資源を溜めない。
