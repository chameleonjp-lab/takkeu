# 虹色コートの球表示と300以降の加速 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** PR #22に、相手側の待機球を隠す従来表示と300以降のラリー増速分1.1倍を追加する。
**Architecture:** `presentation.ts`の表示判定を429f120時点に戻す。`difficulty.ts`の通常増速曲線は299まで維持し、300ラリー目以降の各増分だけ1.1倍にする。
**Tech Stack:** TypeScript, Three.js, Vitest, Playwright.
**Spec:** この会話のPR #22追加修正依頼（相手コートの虹色の上だけ球を表示、300以降の1ラリーごとの加速度を従来の1.1倍）。

## Global Constraints

- 待機球・初期待機球・失球は表示しない。飛行球は相手右190・左240の解放、420で非表示、480で再表示、490の全面虹色という従来条件に戻す。
- 加速の基準は299の速度。300目の増分から1.1倍にし、速度全体やラリーごとの速度そのものへ1.1を掛けない。
- 100以降の残球1球だけ1.2倍、増球、シェア文、ランキングリンク、ポーズの条件を保つ。

## Review Focus

- 待機へ切り替わる瞬間に本体・影・発光の描画を残さない。
- 190の片面解放と420/480の切り替えをGPU画像でも確認する。
- 299→300と300→301の実飛行時間で開始境界を確認する。
- 飛行中の球の増速は位置を飛ばさず、予約と当たり判定へ伝わる。
- 残球1球の追加速度を2球以上へ適用しない。

## Tasks
