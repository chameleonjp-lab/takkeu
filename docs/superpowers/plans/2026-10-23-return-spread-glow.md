# 中央返球と発光ラリーの再確認

基準：main / 公開版 `547cec0654c18c8739752ae1ef322dde42086ee7`（PR #12マージ後）。ユーザーは現在の速度を了承し、左右の返球分散と発光ラリーの確認・修正を依頼した。

## 原因と変更範囲

従来の左右3帯は終点だけを選び、相手の打球位置とは独立していた。遠近投影では、バウンド直後の球が中央のラケットに重なる。実際の相手側配球と次の返球を3,000組生成すると、1,655組（55.2%）を中央固定で返せた。目標点の最小・最大を確認する既存検査では見落としていた。

往路を作る時に次の返球レーンも選ぶ。相手の打球位置と自分への到着位置を同じ左右帯に置き、バウンド後の見える位置まで左右へ分ける。候補は左・右が各約40%、中央が約20%。直前と同じ候補帯は避け、帯内の位置と高さは乱数化する。追加球も同じ経路を使う。最初のサーブは従来どおり中央。

軌道の補間式、接触判定、飛行時間、全球加速、555以後の反射、配球の時間予約は変更しない。対角方向へ戻して中央を通らせる問題を、接触を無効にする方法で回避しない。

## 発光の調査

ユーザーの部位別指定を独立した受入表に書き起こし、直前・到達・翌ラリーを検査する。実接触で0〜555へ進む際の得点・進行・材質を照合し、Chromium / Linux WebKitで各境界の描画画像を保存する。390の脈動で410の自床・420の壁・460の足を先取りしないことも既存検査と併せて確認する。

現時点で部位の解放数値の相違は再現していない。具体的な場所と得点をユーザーへ質問済み。再現できない症状を修正済みと扱わず、検査結果と未確認範囲を分けて提出する。閾値は勝手に動かさない。

## 検証と提出

中央固定の過剰な返球率を先に失敗させ、修正後は25%未満、左右各35%以上、操作範囲内であることを検査する。速度・接触などのソースが基準と同一であることも記録する。型・全単体・全画面（分割実行）・配布用検査、実ドラッグ動画、境界画像を `docs/verification/return-spread-glow/` へ残す。

中央固定で2回返せることを前提にしていた古いテストは、左右に動かす時系列へ直し、30/60/120Hzの同一結果という目的を保つ。音声復旧検査は中央で意図しない2回目の接触がないことを確認する。
