## 落球の条件

| 条件 | 追加する内容 |
| --- | --- |
| 毎回 | 確定時刻の実座標ごとの火花、0.5秒以内 |
| 2秒以内に4球以上 | 台の揺れに低い衝撃音。短いローリング窓で判定 |
| 累計10/20/30/40 | 既存数字に合わせた台外周の衝撃波 |
| 50 | ネット両端の大電撃 |
| 55/77/88 | 既存の特殊数字の位置から光輪0.8秒 |
| 90〜99 | ネット支柱の警告光を維持 |
| 99 | 金色稲妻1.2秒 |
| 100 | 電撃が一斉に広がり終了演出へ。スコアと通信は即時確定 |

既存10単位および55/77/88/99の数字・色・表示時間は維持。終了の物理計算は停止し描画だけ最大5秒継続。再挑戦・ホーム・離脱で状態と音を解放する。

## 検証の判定規則

「成功」は実装と必要な検証の完了、「失敗」は未解消の再現問題、「未確認」は未実施、「対象外」は今回の範囲外。自動信号解析は人間試聴と区別する。Linux性能の実行成功と目標達成は別。実機iPhone17Pro/Safari/VoiceOverは実機がなければ未確認。光安全性は回数に加え相対輝度・赤・領域を評価し、解析の限界を明記する。

優先順位はボール等/スマッシュ警告→終了情報→主要4到達→best→通常一時→背景。抑制しても記録は保持し、古い到達の期限を延長しない。画質で種類/条件を省略しない。カメラ/入力/判定は変えない。描画資源/イベント保持数は上限固定、演出専用の決定的関数のみを使用する。
