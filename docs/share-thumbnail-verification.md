# タッケウ 共有ボタンと固定カード

## 今回の範囲
ホームと結果のX共有を整えます。全15言語の既存本文、結果点数、3500クリア、殿堂番号、正式URLを維持し、末尾の独立行を `#タッケウ #ゲーム制作` に統一します。結果は本文にURLを含み、ホームは既存のintentのURLパラメータを使います。名前は追加しません。

ホーム・結果の常設「共有文をコピー」パネルだけを除き、賞状の保存・共有・コピーは維持します。通常クリックは同期的にblank popupを1回作成し、opener=nullを読み戻した後、同windowのnoreferrer/no-referrerリンクでintentへ移動します。同期的な起動・設定・移動失敗時だけ同じ共有内容を手動コピーpromptに提示します。modifier・中ボタンはnative anchor操作を維持します。自動投稿ではなく、X側の通信失敗を検知するものでもありません。

ゲームルール・3500上限・物理・演出・既存スコア・参加者識別・DB/RPC・音声設定は変更しません。

## 画像
既存 `public/og-takkeu-v1.png`（1200×630）と `src/ui/court-preview.png`、OG/Twitter/canonical設定をそのまま保持します。今回、新しい画像の生成や差替えはありません。既存画像同士の表現を目視照合していますが、新しい実プレイ画面の撮影や配信済みXカードの確認は行っていません。実画面素材の由来・実公開時の見え方の受入は別確認です。

## 検証の区別
次の2ファイルはNode組込みモジュールだけを使います。

```text
node tests/offline/share-text.cjs
node tests/offline/share-popup.cjs
```

- 本文: 実際の共有関数の型注釈を除いた限定コードと15言語のcatalogを使い、75出力ケースを確認します。零・通常値・大きな値・3500クリア・大きな殿堂番号、2タグ各1回、intentと文字数目安を対象にします。不正スコアやクリア不整合の拒否も追加でassertします。280文字相当の計算は簡易的な目安で、実X投稿の受入保証ではありません。
- popup: 実際の限定関数を偽のwindow/documentへ渡す16ケースです。1回のopen、opener読戻し、リンク属性、失敗時の同文prompt、modifier操作を確認します。実popupのreferrerヘッダやブラウザの挙動を証明しません。
- screensへの呼出配線、通常コピーUIの除去範囲、画像・設定の不変は静的差分で確認します。実DOM/全画面起動テストではありません。

既存unit/browser回帰の期待値を追従させ、縦横画面・15言語・黒白/44px・可視矩形・clip・hit・実popupの検証候補と、未知通信/redirectを遮断するテスト補助を含めています。これらのVitest/Playwright、ビルド、全ゲーム、実音声、iPhone実機、実APIは今回実行していません。テスト補助の追加だけで全依存や通信経路の安全性が確認できたとは扱いません。

## 公開・連携
workflow・配備設定・既存画像・DBは変更しません。DraftのCI未実行と、マージ後の公開・実環境受入は区別します。実画面画像/共有カード、実験場リンク、計測・スコア連携の全体受入はこの限定共有変更の完了条件に混ぜず、別途確認します。
