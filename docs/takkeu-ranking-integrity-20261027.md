# タッケウ｜異常記録の隔離・不正送信対策・進行監査

作業日: 2026-10-27（Asia/Tokyo）
対象: `takkeu` のみ。Supabase は他のゲームと共有するため、共通関数の変更はゲーム種別で制限する。
発行状況: この変更群の SQL は同日に共有 Supabase 本番へ適用済み。画面とブラウザ側の変更は **PR をレビューしてマージした後** に GitHub Pages へ反映する。マージはユーザーが行う。

## 判定方針

| ステータス | 表示 | 通常順位 | 使用条件 |
|---|---|---|---|
| `normal` | 通常 | 含める | 成立しない根拠がない |
| `provisional_bot` | 暫定BOT | 除外し、異常記録枠に表示 | プレイ時間・ゲーム仕様から通常では説明できない強い異常。**BOT確定ではない** |
| `bot` | BOT | 除外し、異常記録枠に表示 | 自動操作の具体的な証拠を確認して審査した場合のみ |
| `disqualified` | 通常順位対象外 | 除外し、異常記録枠に表示 | 既存の不正判定を維持 |
| `review`, `hidden` | 非表示 | 除外 | 既存の管理用途。タッケウ以外も含め仕様維持 |

本人確認・BOT確定に IP アドレスの一致のみを使用しない。ブラウザの識別情報、送信時刻、操作のない高スコアなどは「疑いを深める材料」であって断定的証拠ではない。

## 本番処置（変更前の状態は非公開監査テーブルに保存）

- 「💩」の 45,773,300 ラリーを `provisional_bot` とした。プレイ時間約258秒、約177,153ラリー/秒。
- 「あ」の 7,927 ラリーを `provisional_bot` とした。プレイ時間約216秒、約36.6ラリー/秒。同じ登録名には正常に見える別の記録も存在する。**登録名ごとの集計のため、一時的にその名前の順位全体が除外される**。
- 「かみ」11,354 ラリーは現在 `normal` を維持した。プレイ時間約691秒、16.4ラリー/秒。複数球のゲーム仕様を踏まえ、これだけでは不正を証明できない。
- 通常トップは変更後、「かみ」「ガチョ」「ぺる」の順に。既存記録は削除・減点せず保持する。

一度分類した記録を元に戻す場合、`private.takkeu_moderation_audit_v1` とプレイセッションを確認し、手動の管理用 SQL で `ranking_status` 等を変更する。公開側には変更前の監査記録を公開しない。

## 第1段階：画面

`chameleonjp_lab/ranking.html` は `takkeu` に限り `get_takkeu_abnormal_entries_v1` を呼び出す。
曖昧な記録は黄褐色・「暫定BOT」、証拠がある記録は赤色・「BOT」として表示する。
通常順位に混ぜず、異常記録枠は独立表示。公開する理由は簡潔な文章に限定し、IPや端末情報は出さない。
他ゲームの既存「不正ユーザー」欄と RPC を変更しない。

## 第2段階：送信サーバーの確認

1. `finish_game_play_v1` は `takkeu` に限り、スコアと順位用スコアの一致を必須にし、サーバー開始時刻からの秒数を使って `score <= 40 × elapsed_seconds + 150` を要求する。
2. `submit_score_idempotent_v1` は `takkeu` に限り、**終了済みセッションのスコアと送信スコア**の完全一致を要求する。
3. 旧 `submit_score` から `takkeu` を送信できないようにする。他ゲームの呼び出しは変更しない。

40という値は実ゲームの最大30球を参考にした、誤検知を減らすための緩やかな拒否基準。厳密な人間判定ではない。複数球・速度変更・端末の停止／再開を含むテスト後に必要なら調整する。

## 第3段階：高得点の途中経過と追加の確認

`report_takkeu_progress_v1` への **任意** の途中経過を追加。ブラウザは名前登録されたプレイヤーが100ラリー以上のとき、約15秒ごとに送信を試みる。通信失敗でもゲームや結果送信を止めない。

送る値は、そのプレイの `play_id`、表示名とバージョン、ラリー数、ゲーム内の経過秒数、画面内の球数、失った球数。端末の位置情報・IP・操作軌跡は新たに送信しない。

サーバーは同一プレイからの連続報告を5秒未満では拒否し、最大240回までの報告に制限する。通信失敗はゲーム進行や順位登録を止めない。

サーバーは以下を `private` に保存する:
- 直近の途中経過、最初と最後の確認時刻、報告回数。
- 経過秒数やラリー数が逆行した、サーバー時間を超えた、増加が異常だった等の信号。
- 30ラリー/秒を上回る高密度は **要検証の参考信号** であって、自動的なBOT認定や順位停止に使わない。

**限界**: ブラウザが送る途中経過は改ざんできる。短い時間で矛盾した値を送る操作は検出できるが、時間をかけて整合性のある偽スコアを送る攻撃を完全には防げない。確定判定にはサーバー側で計算するゲーム進行、または再現できる操作履歴などが必要で、その実装は別途設計・負荷検証する。

**名前の限界**: 現在は表示名を参加者の識別子として使う。同じ名前の複数人を区別できない。将来の匿名認証・独立参加者IDへの移行は過去の順位移行や個人情報方針が伴うため、このPRで無理に既存の同名記録を分割しない。
